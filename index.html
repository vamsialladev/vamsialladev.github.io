04 · One engagement, stage by stage

One engagement, stage by stage

The hotel project runs like a client engagement, one stage at a time, for the same fictional hotel group.

  1. PSBuilt

    Account Research Agent (pre-sales)

    A cited brief for a first client meeting; every quote re-checked on its page.

  2. 0Live

    Discovery & Scoping

    Stakeholder sessions, use cases scored with a four-check test, SOW, pricing, security answers.

  3. 1Live

    Hotel Operations Knowledge Assistant

    Cited, property-specific policy answers for front-desk staff.

  4. 2Live

    Guest Request Agent

    Drafts cited replies to guest emails; staff approve every send.

  5. 3Live

    Eval Harness

    One eval harness for both assistants: 195 cases, gates in CI, a judge checked against hand labels.

  6. 4Live

    Production Deployment

    Eval-found gaps fixed, redacted persistent logs, budgets in CI, monitoring.

  7. 5Live

    Client Handoff

    Runbooks, SLOs and guides the team can own.

  8. 6Built

    Resort Activities Concierge

    Guests ask about today's activities; the agent sends booking requests that staff approve.

  9. 7Built

    Hotel Tools MCP Server

    The group's tools for any MCP client, with roles, tenant isolation and an audit log.

  10. 8Built

    Ops Analytics Agent

    Plain-English questions over the bookings database, SQL always shown; a daily anomaly check.
